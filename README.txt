STRUCTINSPECT — тестовый PWA-прототип 0.1

ЧТО УМЕЕТ:
- создавать карточки дефектов;
- указывать тип конструкции, марку, оси/ряды, отметку, тип и размеры дефекта;
- прикреплять фотографии с камеры или из медиатеки iPhone;
- хранить записи и фото локально в IndexedDB;
- показывать журнал;
- экспортировать и импортировать резервную копию JSON.

КАК ОПУБЛИКОВАТЬ ДЛЯ ТЕСТА НА IPHONE:
1. Распакуйте архив на компьютере.
2. Разместите содержимое папки на HTTPS-хостинге статических сайтов (например, GitHub Pages или Cloudflare Pages).
3. Откройте полученный HTTPS-адрес именно в Safari на iPhone.
4. Откройте меню «Поделиться» → «На экран Домой» → включите «Открывать как веб-приложение» (если переключатель показан) → «Добавить».
5. Запустите иконку StructInspect, создайте тестовый дефект с фотографией.
6. Дождитесь загрузки приложения, затем включите авиарежим и проверьте, что приложение открывается и запись сохраняется.
7. Вернитесь в раздел «Экспорт» и создайте резервную копию.

ВАЖНО:
- Для работы Service Worker и установки нужен HTTPS (или localhost при разработке).
- Сначала откройте приложение онлайн, чтобы его файлы и Service Worker сохранились на устройстве.
- Данные хранятся локально на устройстве. Это не синхронизация и не резервное копирование.
- Регулярно экспортируйте JSON и проверяйте копию.
- Удаление данных сайта/приложения или очистка Safari может привести к потере локальных данных.
- Это прототип для тестирования интерфейса и сбора информации, не сертифицированная инженерная система.
- Не используйте реальные конфиденциальные данные промышленных объектов без согласования с работодателем.
